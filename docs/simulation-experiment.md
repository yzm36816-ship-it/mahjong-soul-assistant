# RiichiEnv 模拟对局实验 · 2026-09-25

本实验只验证三麻、四麻的事件重建、标签生成、按整场牌局切分、模型训练和看板展示。**没有使用真人雀魂牌谱，不代表实战准确率。**模型未晋级，实时窗口继续只显示规则提示。

## 数据与复现

- RiichiEnv 0.4.10，`GameRule.default_mjsoul()`，每种模式 150 场东风战。
- 自建 `greedy-shanten-v2` 策略：能和牌时和牌，每次可立直时有 35% 概率立直，否则选向听数最低的舍牌；不副露。该策略只用于制造可标注的模拟状态，不代表真人打法。
- 三麻 20,242 条、四麻 35,624 条对手舍牌后样本。模型特征只取自己手牌与公开信息，模拟器提供的对手暗手只用于听牌、等待和荣和标签。
- 数据 SHA256：`4eaf1eccd0b0833351f3dc1143a09f67a91760db867ace379090e6e510b3503f`。公开的 [`examples/simulated/` 事件包](../examples/simulated/riichienv-greedy-v2.events.jsonl.gz) 仅含模拟对局；`tools/rebuild_simulations.py` 重建 300 场后得到相同 SHA256。文件统一使用 LF 换行。仅有 seed 不足以重现 RiichiEnv 0.4.10 东风战后续各局，必须保留此日志。
- 按整场对局分组切分，无同场相邻舍牌跨集合。报告与权重位于被 Git 忽略的 `data/models/`。

## 独立模拟测试

| 指标 | 三麻 | 四麻 |
| --- | ---: | ---: |
| 训练 / 验证 / 测试牌局 | 97 / 24 / 29 | 105 / 23 / 22 |
| 测试舍牌样本 | 3,680 | 5,569 |
| 听牌 Brier：模型 / 巡目规则基线（低为好） | 0.0488 / 0.0474 | 0.0368 / 0.0355 |
| 未立直听牌 Brier：模型 / 基线（低为好） | 0.0535 / 0.0520 | 0.0390 / 0.0378 |
| 未立直听牌召回率 | 6.2% | 1.4% |
| 立直等待 Recall@5：模型 / 训练集先验（高为好） | 33.0% / 27.9% | 24.5% / 28.9% |
| 立直荣和 Brier：模型 / 训练集先验（低为好） | 0.02925 / 0.02934 | 0.03239 / 0.03219 |

模型在两种模式的**听牌 Brier 都未超过规则基线**；四麻等待和荣和指标也落后。未立直召回率很低，说明整体高精确率主要来自公开的立直状态，不能用整体精确率宣传“看穿对手手牌”。即使这些指标超过基线，模拟数据仍不能替代真人对局独立测试，也不会触发实时概率显示。

下一阶段应增加多种模拟策略、检查极度不平衡的正样本，并用来源明确且可复核的真人完整牌谱单独报告结果。视觉识牌准确率还需要三麻、四麻未参与模板制作的视频另行测试。

# 简历展示说明

## 可现场演示

1. 打开本地 Web 看板，切换合成三麻／四麻牌局，沿时间线查看出牌、疑似立直和跟踪缺口，并向本地复盘助手提问“对手听牌了吗”。答案会引用事件且明确未知。
2. 展示桌面小窗口读取指定 Steam 游戏窗口或本地视频，帧数持续变化，异常画面暂停模型预测。
3. 运行合成数据生成与训练命令，在看板对比听牌模型、规则基线、等待与荣和指标。指出模型目前尚未通过真实数据晋级门槛。
4. 展示人工纠错单独存储及公开仓库不含私人截图、视频、牌谱和权重。

## 简历表述建议

“开发 Windows 游戏窗口识别与本地复盘平台，统一实时／视频事件流；设计三麻和四麻的无泄漏训练数据契约、多任务听牌实验与按整场牌局划分的评估门槛；使用 PySide、FastAPI、React 和 SQLite 完成桌面及 Web 交付。”

等拿到足够可使用的真实独立牌局后，再补充准确率、召回率、延迟等实测数字。当前只能称为**模型实验**，不能写成“准确预测对手听牌”。

## 后续互动 AI

第一步是证据约束的本地赛后问答与人工纠错；只允许引用回放事件和已验证规则。纠错进入人工复核后的标注集，不自动训练。后续可增加本地语言模型或用户自选云端讲解服务；语言模型只负责表达和解释，不产生隐藏手牌真值。云端默认关闭，须由用户配置密钥和预算。

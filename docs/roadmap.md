# 后续迭代路线

## 近期：让完整牌局真正可追踪

- 用未参与模板校准的完整三麻与四麻复盘，逐巡标注牌名、舍牌、立直、副露、拔北和新一局，分别测精确率、漏检率、事件缺口率。
- 扩展视觉识别到副露区、宝牌和局数提示，减少目前对人工校对与空牌河判断新局的依赖。
- 让被吃碰移走的舍牌保留在历史事件里，同时记录完整公开牌与置信状态；识别冲突时继续明确暂停模型推断。
- 打通复盘标注底稿与可审计的真实训练 JSONL，保留原始观察、人工修正和来源凭据。

## 模型：从实验走向可报告结果

- 收集自有或授权的完整三麻／四麻牌谱；按整场牌局隔离训练、验证和测试。任何合成样本不得进入实战效果报告。
- 补充完整荣和合法性校验、临时振听和三麻特殊规则；对比听牌、等待、放铳的各自基线，并按巡目、副露、牌型分层。
- 做概率校准与拒答曲线。每种模式必须有足够的独立真人牌局且三项指标均优于基线，才把模型概率送进桌面端。

## 互动 AI：先复盘，再实时

- 将本地赛后问答扩展为事件检索、规则校验和引用证据的多步工具流；加入人工评价题集，检查答案是否引用正确事件、是否越界猜测隐藏手牌。
- 通过人工核验的纠错形成新训练版本，并保留模型版本、数据版本和回滚记录。禁止把助手自己的猜测自动当真值训练。
- 在本地免费方案稳定后，提供用户主动配置的云端讲解接口与用量预算；语言模型只负责表达和教学，规则与预测仍由可测模块提供。

## 产品化

- 可迁移的私有数据目录、模型与配置备份、Windows 独立安装包及 Web 看板的一键启动。
- 分辨率、DPI、主题和遮挡回归；离线诊断包与用户友好的异常恢复。
- GitHub 公开源码、合成演示和评估方法；真实素材及未获明确许可的数据继续私有。

# 产品需求 / v0.1

## 已确认需求

- 主要场景：Windows Steam 雀魂客户端旁的小窗口。
- 输入范围：用户选定的游戏窗口；用户主动提供的截图和视频。
- 四麻、三麻都需要考虑。
- 优先交付可运行、可持续扩展的版本。
- 目标：判断对手听牌倾向，并逐步研究立直后的等待候选。
- 初期费用：本地处理，云端作为后续可选项。
- 所有项目文件放入 `D:/NBA/雀魂麻将助手`，采用分层项目结构。

## 本期交付

1. 窗口枚举与单次 / 连续截取，不回退到全桌面截图。
2. 小窗口展示、模式切换、置顶、可缩放与滚动。
3. 手牌、牌河局部检测与可增量扩充的模板分类。
4. 识别校对和手工牌局输入，区域拖拽校准。
5. 听牌倾向的规则提示，以及针对某个对手的现物 / 筋防守分析。
6. 本地截图、视频逐秒查看；变化快照入库与导出。
7. 测试、架构文档、后续迭代计划、启动和打包脚本。

## 明确未完成

- 自动副露 / 杠 / 拔北 / 立直识别。
- 实时逐事件牌谱、可靠摸切 / 手切识别。
- 经过验证的听牌概率和真实等待牌排名。
- 进攻、防守综合出牌推荐。
- 自动识别新一局、可靠重连恢复。
- 任意主题、任意布局的无校准识别。

## v0.1 验收标准

- 程序能独立打开，通过按钮导入用户截图和视频，产生可检查的检测结果。
- 可选择目标游戏窗口；黑屏、窗口消失 / 最小化不会继续显示可执行的旧分析。
- 未人工确认的牌河不会生成现物安全结论；牌面变化会使相关确认失效。
- 现物结论明确限于对应玩家的荣和；筋不能标为绝对安全。
- 原始素材保持不变；无需 API 密钥和云端调用。
- 独立的规则和状态测试通过，验证报告区分校准素材与真实独立测试。

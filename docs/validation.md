# 验证记录

## v0.3 当前结果

- 46 项自动化测试通过；Web 前端 TypeScript 检查与生产构建通过。
- Windows 源码桌面端导入现有截图并正常渲染退出；本地 FastAPI 服务和浏览器看板实际启动，三麻／四麻合成时间线、模型报告与本地问答可访问。
- 69.57 秒参考视频每 0.5 秒处理一帧，共 139 帧，产生 13 个候选事件，但**可用于模型的完整可信帧为 0**。原因是素材从局中接入且视觉识别未贯通整局；这不能作为端到端牌局跟踪成功证据。
- 两种模式的合成数据训练都正常结束，但均未达到真实独立测试门槛，实时窗口不会显示模型概率。三麻合成测试中的听牌 Brier 还劣于规则基线；绝不据此宣称模型准确。
- 当前没有未参与识别校准的完整三麻与四麻真人牌局数据集；识牌精确率、事件漏检率和听牌模型泛化能力均未达到可报告条件。

## 历史记录 / v0.1

## 已执行

- 规则、输入、确认状态、模式、持久化和关键校对 UI 测试：25 项通过。
- Windows HWND 截图：使用专用 Qt 测试窗口，验证窗口枚举、指定窗口读取和识别；1280×720 画面检测到 64 个牌面候选。没有读取其他现存用户窗口。
- 桌面界面：实际 Windows 渲染并检查中文字体、牌面卡片、三家状态、操作入口和滚动。截图保存在 `artifacts/desktop-preview.png`。
- 用户两张截图：分别检测 14 和 64 个牌面候选，覆盖手牌与当前牌河，不包含副露与宝牌。它们参与模板校准，因此不属于独立准确率测试。
- 用户视频：69.57 秒，30 FPS，2544×1368；提取 9 个参考时点，其中 1.0 秒和 43.2 秒用于补充模板。
- 视频后半段动画、重叠和结算页仍有漏检与未知牌；结算帧手牌检测为 0。未知牌不会自动变成已确认事实。
- 规则引擎仅根据自家手牌和人工确认的公开信息分析，不读取回放中公开的对手手牌。
- 实际 UI 视频流程：导入视频后前进到 1 秒，检测到 13 张手牌，三麻只显示上方 / 右侧两家；验证记录位于 `artifacts/video-ui-qa.json`。
- 独立 Windows 运行包：PyInstaller 构建完成，实际启动、导入截图、渲染并正常退出（exit 0）；预览图位于 `artifacts/packaged-preview.png`。包约 264 MiB，无需安装 Python。

## 尚不能宣称

- 尚未对真实 Steam 客户端的一整场对局完成端到端验收；专用窗口测试不能替代这个环节。
- 模板覆盖 33 / 34 种结构牌，仍缺七万，且方向、缩放、主题变体不完整。
- 本段视频的相邻帧与校准帧高度相关，不能用于声称泛化准确率。
- 尚无听牌 / 等待预测模型的独立验证，启发式不应显示概率或成功率。
- 连续读取是变化快照采样，不保证保留所有出牌、叫牌或新局事件。
